## 4. ダッシュボード

### 実施内容
1. **Init をロール別に 3 API に分割**（旧 `/dashboardinitapi.do` は互換用に残置）
2. 県連/全国連：KPI・お知らせ・テーマ・ヒートマップ・月次を DB から表示
3. 商工会：お知らせ・直近報告 4 件・支援件数を DB から表示
4. ヒートマップ Filter / CellToggle を DB 同期（UI は楽観更新 → API）
5. 組織コード誤参照で「最近登録した報告」が空になる不具合を修正
6. `refreshBottomTable` 未定義で Filter/Toggle が落ちる不具合を修正

### 接続 API

| パス | 用途 |
|------|------|
| `/dashboardnationalinitapi.do` | 全国連ホーム初期 |
| `/dashboardprefinitapi.do` | 県連ホーム初期 |
| `/dashboardshokokaiinitapi.do` | 商工会ホーム初期（直近4件・お知らせ等） |
| `/dashboardheatmapfilterapi.do` | ヒートマップ地方/グループ絞込 |
| `/dashboardheatmapcelltoggleapi.do` | セル除外トグル |
| `/dashboardinitapi.do` | 旧共通 Init（互換） |

### 主なファイル
- 共通：`app/common/dashboard_api.py`
- サービス：`app/service/dashboardroleinitapi/`、`dashboardnationalinitapi/`、`dashboardprefinitapi/`、`dashboardshokokaiinitapi/`、`dashboardheatmap*`
- フロント：`static/mockup/js/dashboard.js`、`router.js`（`#home` 到達時に再描画）

### ロール別の見え方

| 画面ロール | Init API | 主な返却 |
|------------|----------|----------|
| 全国連 | `dashboardnationalinitapi` | KPI・テーマ・都道府県ヒートマップ・月次・お知らせ |
| 県連 | `dashboardprefinitapi` | 同上（ヒートマップは県内商工会） |
| 商工会 | `dashboardshokokaiinitapi` | お知らせ・直近報告4件・支援件数（ヒートマップは組まない） |

### 不具合と対応（本日）

| 症状 | 原因 | 対応 |
|------|------|------|
| 最近登録した報告が空 | `localStorage` の県コードだけ送られ `00/0021` 等で絞られ、シード報告（主に `01/0021`）に当たらない | 組織は両方揃った時だけクライアント送信。否则 session 優先 |
| Filter/Toggle 後に下表が更新されない / API 未送信 | `refreshBottomTable` 呼び出しがあるが関数未定義 | 関数を追加 |
| 商工会の mock お知らせ・件数のまま | Init で recent のみ反映していた | notices / thismonthsupport も反映 |
| ログイン直後ホームが古い | `#home` 遷移で再取得していなかった | `router.js` で `__renderHomeForRole` を呼ぶ |

### 確認メモ
- 直近4件の確認：右上 **商工会** + ログイン **北海道 / 011**（Ctrl+F5）
- 全国連アカウント（`00`）では直近報告シードがほぼ無い
- ヒートマップページ送りは **フロント側のみ**（`/dashboardheatmappageapi.do` は未使用）
