## 1.0.17 （2026-09-17）

### 変更概要

ホーム（ダッシュボード）を顧客設計に合わせる。①ログイン session の組織名／ユーザー名を `get_current_organization`／`get_current_user` 経由で側欄へ表示。②お知らせは `role_code` 権限・有効期間（未設定日は年度末まで補完、期限切れ非表示）。下書き件数・今月支援件数・直近報告・`cfg_menu_item` メニューも Init から反映。あわせて県連／全国連の「今月の支援件数」を月次表合算（ヒートマップと同口径）にし、ロール切替デモのメニュー残留を解消。

***

### 変更詳細

| 変更番号 | 変更対象 | 変更内容 | 変更理由 |
| ---- | ---- | ---- | ---- |
| 1 | `app/common/session.py` | `get_current_organization`／`get_current_user`／`refresh_session_profile` 追加。ログイン／2FA 時に `ORG_NAME` 等を session へ | 顧客設計①（側欄はログイン組織／ユーザー） |
| 2 | `app/dashboard/services.py`／`app/manual_input/services.py`／`app/common/menu.py` | お知らせ・下書き件数・今月支援・KPI・直近報告・メニュー取得 | 顧客設計のサービス関数に合わせるため |
| 3 | `app/common/dashboard_api.py` | Init に `orgname`／`userid`／`username`／`draftcount`／`menus`／件数を載せる。商工会は組織 COUNT、県連／全国連は `monthly_stats` 合算 | 画面口径と顧客設計を一致させるため |
| 4 | `static/mockup/js/org_role_switcher.js`／`dashboard.js`／`router.js` | 側欄を session／Init から更新。下書きは件数>0 のみ。メニューは `cfg_menu_item` 連動＋ロール切替時の即時フォールバック | ハードコード表示とメニュー残留をやめるため |
| 5 | `ddl_define.sql`／`templates/app.html`／`docs/変更履歴.md` | 有効なお知らせ種子の end_date 調整、初期 HTML の固定文言削除、キャッシュ bust、本版記録 | 期限切れ非表示の確認と旧 JS 残留防止 |

***

### 画面仕様メモ（確定挙動）

| 項目 | 挙動 |
| --- | --- |
| 側欄 組織名／ユーザー | ログイン組織・ユーザー（DB）を優先。ロール切替デモでは色のみ変更 |
| お知らせ | `zenkoku`／`ken`／`shokokai` 別。期間外は非表示。日付 NULL は年度末（3/31）まで補完 |
| 下書きお知らせ | `draftcount>0` のときのみ「…がN件あります」を追加表示 |
| 今月の支援件数 | 商工会：自組織の `trn_report` COUNT。県連／全国連：月次表（ヒートマップ同口径）の当月／前月合算 |
| メニュー | `cfg_menu_item` の `screen_id` → route。ロール切替直後はフォールバック表示、Init 後に正式反映 |

***

### 確認メモ

- Ctrl+F5 後、ログインすると側欄がログイン組織／ユーザーになること（ロール切替しても組織名は変わらない）
- お知らせはロール別に分かれ、期限切れが出ないこと
- 下書き 0 件のとき下書きリンクが出ないこと
- 県連／全国連ホームの「今月の支援件数」が月次表合計と一致すること
- ロール切替直後に受付／ナレッジ管理メニューがちらつかないこと
